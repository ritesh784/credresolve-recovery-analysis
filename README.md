# CredResolve Recovery Analysis

## Overview

This project reconstructs recovery performance from operational collection data, investigates data-quality and attribution issues, evaluates the reported 11% improvement, and recommends where the ₹10 Cr investment should be deployed.

## Project Structure

| Folder | Contents |
|---|---|
| `01_data` | Golden datasets and data-quality outputs |
| `02_notebook` | Python analysis and data-processing work |
| `03_sql` | SQL analysis queries |
| `04_dashboard` | Power BI dashboard |
| `05_architecture` | Production analytics architecture |
| `06_executive_memo` | Executive summary and recommendations |
| `07_documentation` | Methodology, assumptions and metric definitions |

## Key Analysis Areas

- Recovery performance reconstruction
- Duplicate and payment-quality investigation
- Recovery attribution
- Recovery trends
- Borrower and account segmentation
- Channel and provider analysis
- Evaluation of the reported 11% improvement
- ₹10 Cr investment recommendation

## Tools Used

- Python
- Pandas
- SQL
- Power BI
- GitHub

## Deliverables

The repository contains the analytical datasets, analysis code, SQL queries, dashboard, architecture diagram, and executive recommendation required for the CredResolve case study.
